Installation Instructions

  1. Download both files from Google Drive:
    • katipudroid.apk - The application installer
    • main.obb - Game data file
  2. Enable "Install from Unknown Sources"
    Go to Settings → Security → Install Unknown Apps
    Enable permission for your browser or file manager
  3. Install the APK
    Open the downloaded .apk file and tap Install
  4. Copy OBB file to the correct folder
    Move main.obb to:
    Android/obb/com.katipudroid.game/
    (Create the folder if it doesn't exist)
  5. Launch KATIPUDROID
    Open the app from your home screen and enjoy the game!
